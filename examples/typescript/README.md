# TypeScript examples

These mirror the C++ examples in [`../cpp`](../cpp) one-for-one, using the same
shared schemas in [`../schema`](../schema). Every frame they produce is
byte-for-byte identical to the C++ and Python output.

The TypeScript runtime is a dependency-free `Codec` plus framing/session helpers
(see [`packages/upr_typescript`](../../packages/upr_typescript)). It does **not**
include the C++ `StreamRuntime`, `SpanTransport`, framers, partial decode,
segmented zero-copy encode, discovery, or the HTML workbench — the examples note
where a C++ feature has no TypeScript equivalent and what to use instead.

## Layout

| File | Mirrors | Features shown |
| --- | --- | --- |
| `market_data_demo.ts` | `cpp/src/upr_demo.cpp` | encode + fixed-size frame decode, enums, `ascii[N]`, `float32`, typed interfaces |
| `market_data_decode_example.ts` | `cpp/src/market_data_decode_example.cpp` | repeating groups, tagged variants, presence-gated optionals |
| `sensor_packet_encode_example.ts` | `cpp/src/sensor_packet_encode_example.cpp` | derived length fields, reserved + alignment gaps, dynamic `bytes`, validation invariant |
| `hardware_byte_stream_example.ts` | `cpp/src/hardware_byte_stream_example.cpp` | length-prefixed framing + streaming `FrameDecoder` |
| `framing_and_session_example.ts` | (cross-cutting) | `encodeFrame`/`tryReadFrame`/`iterFrames`/`FrameDecoder`, `UPR1` handshake, checksums |
| `generated/` | — | protocol modules generated by `upr-gen` (see below) |

## Run

The `generated/` modules are **not** committed. Generate them once after a fresh
checkout (and again whenever a schema changes):

```bash
python3 examples/generate_bindings.py
```

The examples depend on the in-repo runtime package via a `file:` dependency.
Build the runtime once, install, then run any example with Node's native
TypeScript support (Node ≥ 22.6):

```bash
cd examples/typescript
npm install            # links universal-protocol-runtime from ../../packages/upr_typescript
npm run build:runtime  # builds that package's dist/ (one-time, or after runtime changes)

npm run market-data-demo
npm run market-data-decode
npm run sensor-packet-encode
npm run hardware-byte-stream
npm run framing-and-session
# or run them all:
npm run all
```

Type-check the examples with `npm run typecheck`.

## Regenerating `generated/`

`examples/generate_bindings.py` produces all three modules from the shared
schemas with the `upr-gen` tool. To generate a single module by hand:

```bash
bazel run //packages/upr_codegen:upr-gen -- \
    --lang typescript \
    --input examples/schema/advanced_market_data.upr \
    --output examples/typescript/generated/advanced_market_data.ts \
    --runtime-import universal-protocol-runtime
```

Wide integers (7- and 8-byte fields, e.g. `TradeDetail.trade_id`) decode to
`bigint`; narrower integers and floats decode to `number`.
