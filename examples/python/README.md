# Python examples

These examples use the Python runtime package with protocol modules generated
from the shared schemas in [`../schema`](../schema). The generated modules expose
both a dict-oriented `CODEC` and typed dataclasses for each message.

The Python runtime ships a dependency-free `Codec` plus framing/session helpers
(see [`packages/upr_python`](../../packages/upr_python)). It does not provide
socket transports; use normal Python socket/file APIs and pass received bytes to
`FrameDecoder`.

## Layout

| File | Features shown |
| --- | --- |
| `market_data_demo.py` | encode + fixed-size frame decode, enums, `ascii[N]`, `float32`, typed dataclasses |
| `market_data_decode_example.py` | repeating groups, tagged variants, presence-gated optionals |
| `sensor_packet_encode_example.py` | derived length fields, reserved + alignment gaps, dynamic `bytes`, validation invariant |
| `hardware_byte_stream_example.py` | length-prefixed framing + streaming `FrameDecoder` |
| `framing_and_session_example.py` | `encode_frame`/`try_read_frame`/`iter_frames`/`FrameDecoder`, `UPR1` handshake, checksums |
| `generated/` | protocol modules generated by `upr-gen` (see below) |

## Setup

Install the runtime package (editable is convenient for in-repo work), then
generate the protocol modules — the `generated/` folders are **not** committed:

```bash
python3 -m pip install -e packages/upr_python    # or: python3 -m pip install universal-protocol-runtime
python3 examples/generate_bindings.py
```

Run those commands from the repository root. If your Python installation reports
an externally-managed environment, use a virtual environment for the editable
install.

## Run

From this directory, run any example directly:

```bash
cd examples/python
python3 market_data_demo.py
python3 market_data_decode_example.py
python3 sensor_packet_encode_example.py
python3 hardware_byte_stream_example.py
python3 framing_and_session_example.py
```

Each script imports `universal_protocol_runtime` (from the installed package)
and its `generated` protocol module (resolved from this directory, which Python
puts on the import path automatically when you run a script from here).

## Regenerating `generated/`

`examples/generate_bindings.py` produces all three modules from the shared
schemas with the `upr-gen` tool and lightly adapts them to use the pure-Python
`Codec` (so they run without building the native pybind11 extension). To
generate a single module by hand:

```bash
bazel run //packages/upr_codegen:upr-gen -- \
    --lang python \
    --input examples/schema/advanced_market_data.upr \
    --output examples/python/generated/advanced_market_data.py
```

For maximum throughput in production, generate the native-backed module instead
(drop the adaptation step) and build the emitted `_*_native.cpp` extension; the
encode/decode API is identical.
